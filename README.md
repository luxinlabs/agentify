# Agentify

Turn any merchant catalog into **agent-native** listings.

Agentify is the open-source SDK + CLI for the [Argosy](https://github.com/luxinlabs/argosy) Agent-Native Product (ANP) schema. It takes your existing store — Shopify, WooCommerce, CSV, or a custom API — and produces machine-readable product listings that AI agents can discover, compare, trust, and buy from, with zero human UI.

No dependencies. Runs anywhere Node 20+ runs.

## Install

```bash
npx agentify --help        # or: npm i -g agentify
```

## Quickstart

```bash
# 1. Convert your catalog to ANP listings
agentify init --from csv --input products.csv --out ./anp

# 2. Grade your catalog's agent-readiness
agentify audit --from csv --input products.csv

# 3. Publish to an Argosy marketplace
agentify publish --dir ./anp --to argosy \
  --api-url http://localhost:8000 --merchant-id 1
```

## Commands

### `init` — generate ANP listings

```
agentify init --from <csv|json|shopify> --input <path> --out <dir> [--source <name>]
```

- `csv`: any CSV with columns like `id,name,brand,description,category,price,currency,stock,sku,image_url,shipping_days,returns_allowed,warranty,specs`
- `json`: array of product objects (or `{products: [...]}`)
- `shopify`: a store domain — reads the public `/products.json` feed, no auth needed

Writes one `<id>.anp.json` per product plus `index.json`. Every file is validated
against the ANP v0.1 schema before it's written; invalid rows are reported, not silently dropped.

### `audit` — agent-readiness score

```
agentify audit --from csv --input products.csv
```

Grades your catalog 0–100 across five dimensions:

| Dimension | Weight | What it checks |
|---|---|---|
| structured_data | 30% | id, name, price, currency present |
| policy_completeness | 25% | returns + warranty declared |
| commercial_state | 20% | price, currency, stock present |
| discoverability | 15% | category, description, image |
| checkout_readiness | 10% | checkout/UCP endpoint present |

### `publish` — ship listings to Argosy

```
agentify publish --dir ./anp --to argosy --api-url <url> --merchant-id <id>
```

Re-validates every file, then ingests each listing into the Argosy marketplace
via `POST /listings/ingest`. Listings generated by agentify are guaranteed
ingestible — the CLI's validator mirrors Argosy's server-side checks.

## The ANP schema

See [`anp/schema/anp-0.1.json`](anp/schema/anp-0.1.json). An agent-native listing carries:

- **Structured product data** — typed specs, not marketing copy
- **Machine-readable policies** — returns, shipping, warranty, authenticity as rules an agent can reason over
- **Live commercial state** — real-time price and inventory
- **Checkout endpoints** — UCP / ACP compatible
- **Trust attestation** — signed pointer to the merchant verification record
- **Provenance** — where the data came from, and when it was last verified
